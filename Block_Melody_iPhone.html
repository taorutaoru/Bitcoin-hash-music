動作について

10秒ごとに最新ブロック高を確認し、高さが変わったときだけハッシュを取得してメロディを更新します。音はブラウザ内で生成します。Safariの画面を開いたまま使用してください。

API：mempool.space REST API

試作版です。ブラウザやネットワークの制限でAPI接続が失敗する場合は、HTTPSで公開したページから開く必要があります。
